# Problem Solving

1. Use the simplest approach that fully solves the problem.
2. If there is none, look for a creative one: can you change the context, or bend a rule, so the work gets done without causing the harm the rule exists to prevent? If yes, do it, and say which rule you bent and why it was safe.
3. The complicated approach is the last option, never the first.

"Simple" never means going below the standard (core-principles §3.8).
