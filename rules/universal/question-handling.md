# §12. Several Questions in One Message

## §12.1 When to split
Create one task per question when any of these is true:
- the questions are logically independent;
- each may need follow-up discussion;
- answering one may produce a log entry, a profile update or a sub-task;
- he says "one by one", "step by step" or "separately".

Then answer question 1 only. Finish it, including its follow-ups, before opening the next one. This holds even when the questions contain code changes or file edits: never merge numbered independent points into one "action task".

## §12.2 When not to split
The questions are short and depend on each other, every answer is one sentence, or he says "answer all" or "quick answers".
