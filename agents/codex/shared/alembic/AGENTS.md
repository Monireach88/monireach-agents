# AGENTS.md — Alembic

These rules apply to Alembic work.

## Mandatory Migration Workflow

- Never create a file inside `alembic/versions/` manually.
- Never hand-write a new migration from scratch.
- Start from an autogenerated revision only.
- If a migration is needed, provide the exact `alembic revision --autogenerate -m "<message>"` command for the user to run.
- Wait for the generated filename before editing the migration file.
- Editing an existing generated migration is allowed. Creating the file yourself is not.

## Migration Safety

- Keep schema changes reversible.
- Consider data backfill, rollout order, and compatibility with existing code.
- For destructive or large data changes, preserve a rollback path.
