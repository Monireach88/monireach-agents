# Start HF Spaces

Scaffold a Python FastAPI project targeting HuggingFace Spaces deployment. Fully self-contained.

## When This Skill Applies

- User invokes `/start-hf-spaces`
- User asks to "scaffold an HF Space project", "set up a HuggingFace Spaces project"

---

## Instructions for Agent

### Step 1: Ask User

Ask these questions all at once:

1. **Project name** — used for Docker tags, /etc/hosts entry (e.g., `my-chatbot`)
2. **One-line description** — used in README and PROJECT.md
3. **HF username** — your HuggingFace username (e.g., `mt-robotics`)
4. **HF Space name** — the Space name on HuggingFace (e.g., `my-chatbot`)

### Step 2: Confirm Working Directory

Tell the user: "I'll create files in the current directory: `<cwd>`. Is that correct?"

Wait for confirmation before creating files.

### Step 3: Create All Files

Create every file listed in the File Spec below.

### Step 4: Print Post-Setup Checklist

```
✅ HF Spaces project scaffolded! Next steps (run manually):

□ git init && git remote add origin <github-url>
□ git add . && git commit -m "init: project scaffold"
□ uv sync
□ Add /etc/hosts entry: 127.0.0.1 <project-name>.local
□ Create HF Space at huggingface.co/spaces/<hf-username>/<hf-space-name>
  → SDK: Docker | Port: 7860 | Visibility: Public
□ Add GitHub secret: HUGGINGFACE_TOKEN
  (Settings → Secrets and variables → Actions → New repository secret)
□ Set HF Space secrets (Settings → Variables → New secret):
  - GROQ_API_KEY=<your-key>
  - SYSTEM_PROMPT=You are a helpful assistant.
  - DATABASE_URL=sqlite:///./chatbot.db
  - CORS_ORIGINS=*
□ Build HF target locally to verify:
  docker build --target huggingface -t <project-name>:hf .
□ Run tests:
  uv run pytest
□ Push to main → CI/CD deploys to HF Space automatically
```

app = FastAPI(title="<Project Name>")

app.add_middleware(
    CORSMiddleware,
    allow_origins=cors_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/health")
def health():
    return {"status": "ok"}


@app.get("/api/")
def root():
    return {"message": "Welcome to <Project Name>"}


# Mount frontend LAST (catches all unmatched routes)
if os.path.exists("frontend"):
    app.mount("/", StaticFiles(directory="frontend", html=True), name="frontend")

## HF-Specific Notes

- **Port:** HF Spaces Docker SDK requires port 7860. The `huggingface` Docker stage uses this port.
- **Public Space:** Must be public for external `fetch()` calls from the frontend to work without authentication.
- **Heredoc in YAML:** All content inside a heredoc block must be indented to match the YAML block base indentation level or the EOF marker won't be recognized.
- **frontend/config.js:** NOT gitignored. CI overwrites it during deploy with the production API URL.
- **Same-origin:** When FastAPI serves the frontend via `StaticFiles`, the API URL can be empty string `""` because requests are same-origin (HF Space host = API host).
- **rsync excludes:** Always exclude `assets/` and binary files from rsync to avoid HF git push rejection.
